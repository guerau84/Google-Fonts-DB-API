### Rules

| Field | Source | Rule |
|---|---|---|
| `fonts` | `fonts.length` | literal |
| `categories` | unique `category` | count of distinct values |
| `subsets` | unique non-`menu` subset | `menu` excluded (internal, not a script) |
| `designers` | unique `designer.name` | count of distinct names |
| `variable.families` | `variable === true` | count |
| `variable.percentage` | computed | `(variableFamilies / fonts × 100)`, rounded to 2 decimals |
| `styles` | each font's `styles[]` | count occurrences per style |
| `weights` | each font's `weights[]` | count occurrences per weight, keys as strings `"100"`…`"900"` |
| `categories` (nested) | each font's `category` | count per category |
| `subsets` (nested) | each font's `subsets[]` | count per subset, `menu` excluded |
| `axes` | each font's `axes[].tag` | count per tag, as-is (no case normalization) |

Ordering: key insertion follows the output format above; map-like breakdowns sorted by `count` descending (stable, then key ascending) to keep output deterministic.

## Proposed implementation in `src/scripts/extract-stats.ts`

1. **Paths** (relative to the project root):
   - `SRC = src/data/fonts.json`
   - `OUT = src/data/stats.json`
2. **Read**: `readFile` + `JSON.parse` of `fonts.json`. If missing or corrupt, abort with an error.
3. **Single pass** over `fonts` building: `variableFamilies`, `Set` of designers, and `Map`s for `styles`, `weights`, `categories`, `subsets` (skip `menu`), `axes`.
4. **Assemble** the stats object in the output key order; compute `percentage` as `Math.round(variableFamilies / fonts * 10000) / 100`.
5. **Write**: `JSON.stringify(stats, null, 2)` + trailing newline (blank lines between top-level groups preserved via a single object literal).
6. **Logging**: total fonts, variable %, designers, subset and axis counts.
7. **Entrypoint**: `main()` with `await`, ESM; run with `npx tsx src/scripts/extract-stats.ts`. No changes to `package.json`.
