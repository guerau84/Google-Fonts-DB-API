# Plan: `extract-families.ts` — Generate `src/data/families.json`

## Context

- Source: `src/data/fonts.json` (array of **2022** fonts), generated by `docs/organize-fonts.md`.
- Target: `src/data/families.json` (currently empty, scaffold). Do not touch `src/fonts/*`, `src/categories.ts`, etc.
- Goal: extract only the family metadata (without links, css, previews) into a lightweight format.
- Only this plan MD is delivered in this task; the implementation is left for the next one.

## Key transformations (source → target format)

| Source (`fonts.json`) | Target (`families.json`) | Rule |
|---|---|---|
| `id` | `id` | literal |
| `family` | `family` | literal |
| `category` | `category` | literal |
| `designer.name` (`{name}` object) | `designer` (string) | extract `.name` |
| `variable` | `variable` | literal |
| `styles` | `styles` | literal |
| `weights` | `weights` | literal |
| `subsets` | `subsets` | literal (keeps `"menu"`) |
| `axes` (array of `{tag, min, max}`) | `axes` (array of `tag` strings) | map `[{tag,min,max}] → [tag]`; `[]` if static |

### Cases verified in `fonts.json`

- `designer` is always `{name: string}` (0 entries without `.name`).
- `variable: true` ⇒ `axes` is non-empty (0 exceptions).
- `variable: false` ⇒ `axes: []` (0 exceptions).
- Total families: **2022** → `total: 2022`.
- Possible axis tags (49 total): `ARRR, BLED, BNCE, CASL, CRSV, CTRS, EDPT, EHLT, ELGR, ELSH, ELXP, FLAR, GRAD, HEXP, INFM, MONO, MORF, opsz, ROND, SCAN, SHLN, SHRP, slnt, SOFT, SPAC, SZP1, SZP2, VOLM, wdth, wght, WONK, XELA, XOPQ, XPN1, XPN2, XROT, XTRA, YEAR, YELA, YOPQ, YPN1, YPN2, YROT, YTAS, YTDE, YTFI, YTLC, YTUC` → passed through as-is (no case normalization).

## Output format

```json
{
  "families": [
    {
      "id": "42dot-sans",
      "family": "42dot Sans",
      "category": "sans-serif",
      "designer": "42dot",
      "variable": true,
      "styles": ["normal"],
      "weights": [400],
      "subsets": ["korean", "latin", "menu"],
      "axes": ["wght"]
    }
  ],
  "total": 2022
}
```

## Proposed implementation in `src/scripts/extract-families.ts`

1. **Paths** (relative to the project root):
   - `SRC = src/data/fonts.json`
   - `OUT = src/data/families.json`
2. **Read**: `readFile` + `JSON.parse` of `fonts.json`. If missing or corrupt, abort with an error.
3. **Mapper** `toFamily(entry)`:
   - `designer: entry.designer.name`
   - `axes: entry.axes.map(a => a.tag)`
   - remaining fields copied as-is, in the order of the output format.
4. **Write**: `JSON.stringify({ families, total: families.length }, null, 2)` + trailing newline.
5. **Logging**: total families processed.
6. **Entrypoint**: `main()` with `await`, ESM; run with `npx tsx src/scripts/extract-families.ts`. No changes to `package.json`.
