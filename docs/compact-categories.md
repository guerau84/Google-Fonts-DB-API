# Plan: Compact `categories.json` — Drop the `families` Field

## Context

- Source: `src/data/categories.json` (5 category objects, each `{ id, name, count, families }`), generated by `docs/extract-categories.md`.
- Target: `src/data/categories.compact.json` (new file). Generate a lightweight index that **removes the `families` array**, keeping only `id`, `name`, `count`.
- Do not touch `src/data/categories.json`, `src/data/fonts.json`, `src/scripts/*`, `package.json`, etc.
- Goal: a slimmer payload for consumers that only need category metadata and counts, without the full per-family listings.
- Only this plan MD is delivered in this task; the implementation is left for the next one.

## Data notes (verified against `categories.json`)

- The source has **5** categories, in canonical order:
  `sans-serif`, `serif`, `display`, `handwriting`, `monospace`.
- Current `count` values (sum = **2022** total fonts):
  - `sans-serif` 756
  - `serif` 362
  - `display` 503
  - `handwriting` 355
  - `monospace` 46
- `count` is already present and correct, so the compact step only needs to drop `families` (it never recomputes counts).

## Output format

```json
{
  "categories": [
    { "id": "sans-serif", "name": "Sans Serif", "count": 756 },
    { "id": "serif", "name": "Serif", "count": 362 },
    { "id": "display", "name": "Display", "count": 503 },
    { "id": "handwriting", "name": "Handwriting", "count": 355 },
    { "id": "monospace", "name": "Monospace", "count": 46 }
  ],
  "total": 5
}
```

### Rules

| Point | Decision |
|---|---|
| `id` | copied as-is from `categories.json` |
| `name` | copied as-is from `categories.json` |
| `count` | copied as-is from `categories.json` (do not recompute) |
| `families` | removed entirely (do not emit `families: []` or an empty array) |
| Order | preserved: `sans-serif`, `serif`, `display`, `handwriting`, `monospace` |
| `total` | `categories.length` (5) |

## Proposed implementation in `src/scripts/compact-categories.ts`

1. **Paths** (relative to the project root):
   - `SRC = src/data/categories.json`
   - `OUT = src/data/categories.compact.json`
2. **Read**: `readFile` + `JSON.parse` of `categories.json`. If missing or corrupt, abort with an error.
3. **Map**: `categories.map(({ id, name, count }) => ({ id, name, count }))` — destructuring drops `families`.
4. **Write**: `JSON.stringify({ categories, total: categories.length }, null, 2)` + trailing newline.
5. **Logging**: total categories and total fonts (sum of counts).
6. **Entrypoint**: `main()` with `await`, ESM; run with `npx tsx src/scripts/compact-categories.ts`. No changes to `package.json`.
