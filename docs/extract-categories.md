### Rules

| Point | Decision |
|---|---|
| `id` | `category` as-is from `fonts.json` |
| `name` | title-case each hyphen-separated token (`sans-serif` → `Sans Serif`); `serif`/`display`/`handwriting`/`monospace` map to themselves capitalized |
| `count` | number of fonts in the category |
| `families` | font `id`s, in source order (order of appearance in `fonts.json`) |
| Order | fixed canonical order: `sans-serif`, `serif`, `display`, `handwriting`, `monospace` (matches the requested example) |
| `total` | `categories.length` (5) |

## Proposed implementation in `src/scripts/extract-categories.ts`

1. **Paths** (relative to the project root):
   - `SRC = src/data/fonts.json`
   - `OUT = src/data/categories.json`
2. **Read**: `readFile` + `JSON.parse` of `fonts.json`. If missing or corrupt, abort with an error.
3. **Aggregate** with a `Map<category, string[]>`: for each font, push `font.id` into the map entry for `font.category`.
4. **Build entries** `{ id, name, count: families.length, families }` for the 5 categories in canonical order.
5. **Write**: `JSON.stringify({ categories, total: categories.length }, null, 2)` + trailing newline.
6. **Logging**: total categories and fonts processed.
7. **Entrypoint**: `main()` with `await`, ESM; run with `npx tsx src/scripts/extract-categories.ts`. No changes to `package.json`.
